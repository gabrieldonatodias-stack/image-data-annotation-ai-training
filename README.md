- Animal

## Workflow
Image → Annotation guideline → Label → Confidence → Quality control → Dataset/report

## Repository structure

- docs/annotation_guidelines.md

## Portfolio result
30 synthetic visual samples are organized into a structured annotation dataset. The project demonstrates consistency, attention to detail, metadata handling and quality control.
