# Annotation Guidelines

## 1. Purpose

These guidelines define how images should be classified in this portfolio dataset. The objective is to maintain consistent annotations across the dataset.

## 2. General Rule

Classify the primary object represented by each record. If multiple objects are visible, select the category corresponding to the object being annotated.

## 3. Categories

### Vehicle
Cars, motorcycles, bicycles, buses and trucks.

### Animal
Dogs, cats, birds, horses and other animals.

### Person
Use when the annotated subject is a human.

### Food
Use for identifiable food items or meals.

### Electronic Device
Smartphones, laptops, tablets, monitors, cameras and similar devices.

## 4. Confidence

- High — clearly identifiable.
- Medium — identifiable but with some ambiguity.
- Low — difficult to determine reliably.

## 5. Ambiguous Images

1. Review the image again.
2. Compare it with the category definitions.
3. Select the most appropriate category when possible.
4. Record uncertainty in the notes field.
5. Mark the record for quality-control review.

## 6. Consistency

Similar objects should receive the same category throughout the dataset.

## 7. Quality Principle

Annotations should be accurate, consistent, reproducible, clearly documented and based on predefined rules.
