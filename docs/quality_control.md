# Quality Control

## Pre-submission checklist
- Category matches the visual subject.
- Taxonomy spelling is correct.
- Annotation ID is unique.
- Confidence is between 0 and 1.
- Ambiguous samples are flagged.
- Required fields are complete.

## Review process
1. Check label consistency.
2. Check metadata.
3. Review low-confidence samples.
4. Correct issues.
5. Approve the dataset.

A high-quality AI dataset must be consistent, traceable and fit for the intended model task.
